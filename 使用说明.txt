PRD 工作台 1.0.1（Windows x64）

Codex 内预览（新增）
双击本目录“启动Codex预览.bat”，或在本目录执行 npm.cmd run preview。
服务启动后，在 Codex 内置浏览器打开启动窗口显示的网址，默认 http://127.0.0.1:4173。
如果端口被占用，使用启动窗口显示的实际地址。启动窗口需要保持运行。
预览与桌面版共用界面和文档格式；PRD、草稿、历史、备份仍保存到本地文件，不依赖浏览器缓存。
选择项目、打开文件和保存位置使用页面内文件选择器，可直接输入完整目录路径并点击“转到”。
预览模式的项目列表、最近记录保存在本目录 preview-data；桌面版项目列表保持独立。
浏览器刷新会恢复服务中当前文档及已保存草稿；服务重启后可从“最近打开”重开文档。
修改界面代码后刷新预览页；修改本地服务代码后需重启预览服务。文件类型关联仍由桌面版设置。

一、选择版本
PRD-Workspace-1.0.1-Setup.exe：安装版，可选择安装位置，创建快捷方式并注册 .prdproj 文件类型。
PRD-Workspace-1.0.1-Portable.exe：便携版，双击直接运行，首次启动需要解压运行时，请稍候。
两个版本功能一致，无需网络。程序目录与项目数据分开，升级程序不会覆盖 PRD 文件。

二、开始使用
文档标签栏：打开多份 PRD 后，每份文档显示一个标题标签，点击即可切换，× 关闭标签，不会删除文档。
切换或关闭前会先保存；当前打开期间，各标签分别保留编辑草稿和撤销/重做记录。
文档标题修改后标签同步更新；同一文件重复打开不会生成重复标签；标签栏右侧“＋”用于新建 PRD。
1. 点击“创建项目”，直接选择已有项目文件夹，项目名称自动使用文件夹名称，无需输入。软件不会移动原有文件。
2. 点击“新建 PRD”，填写名称，选择项目目录中的任意子文件夹保存。
3. 左侧“新增模块”，在模块中“新增数据项”，即可编写正文、表格和评审记录。
4. 点击“文档总览”查看项目文档，再点击“返回编辑”回到当前文档。
5. 也可以直接“打开 PRD 文件”，无需先创建项目。项目目录搬家后可“重新定位”。

三、文件与迁移
文档标题和“修改标题”位于模块导航栏顶部；修改后同步更新标题标签。保存、另存为和只读归档统一使用顶部工具栏。
“导入旧 HTML”和“清空本文档”位于顶部“更多”菜单；卡片“上移、下移、删除”位于该卡片“更多”菜单。
历史需求总览、评审记录总览，以及卡片的历史需求、评审记录功能均保留。
编辑器已移除浏览器缓存合并、缓存迁移及 HTML 自我导出代码。文件写入由宿主程序统一处理。
每份文档是独立的 .prdproj 文件，采用 UTF-8 JSON 完整快照格式，正文、表格、评审、历史、回收站及未提交草稿均保存在其中。
复制此文件即可携带文档，不依赖浏览器缓存。项目列表和最近记录保存在当前 Windows 用户的应用数据目录。
原 HTML 文件请使用“导入旧 HTML”。如果最新内容还在浏览器缓存，先在旧工具点击“保存文件”，再导入下载的新 HTML。
示例文档已移至 E:\PRD与评审记录工具\实例\示例-行业监管驾驶舱.prdproj，可直接打开。该文件保留用户已编辑的数据，原始测试模板另保存在 desktop/templates 中。

四、自动保存与草稿
编辑停止约 0.9 秒后自动保存，Ctrl+S 可立即保存；切换文档和退出程序前也会完成保存。
编辑弹窗中的未提交内容作为草稿一同保存，重开文档会恢复弹窗；点击弹窗内“保存”后才提交到正文或评审记录。
关闭/取消编辑弹窗会丢弃未提交草稿，可在本次打开期间通过撤销找回。
右上角显示“等待保存 / 正在保存 / 已保存（含编辑草稿）/ 保存失败”。保存失败时窗口不会自动关闭，请另存为可写位置。
如文件被其他程序修改，程序会阻止覆盖，请另存为以保留当前内容，或重新打开磁盘文件。

五、撤销与重做
Ctrl+Z：撤销；Ctrl+Y 或 Ctrl+Shift+Z：重做。
覆盖正文草稿、表格、模块、卡片、评审等文档编辑。相近连续输入合并为一个撤销步骤，最多保留 80 个步骤。
撤销记录仅保留在本次文档打开期间，关闭/重新打开或恢复备份后重置。长期恢复使用历史需求或自动备份。
Ctrl+N：新建 PRD；Ctrl+O：打开；Ctrl+Shift+S：另存为。

六、备份与恢复
备份放在文档同目录的“.prd-backups\原文件名.prdproj\”中；自动备份每 5 分钟，最多保留最近 30 份。
保存时会在需要的情况下先备份旧文件。也可以在“备份与恢复”中点击“立即备份”。
恢复备份前会再备份当前文件。移动整个项目时请一并复制 .prd-backups；单独复制 .prdproj 不包含外部备份。
如原文件损坏无法打开，可在资源管理器中打开隐藏的 .prd-backups，复制一份备份到正常目录，再从软件打开。
删除模块/卡片会进入回收站，保留正文、表格、评审和历史，支持恢复。清空整个文档前自动生成备份。

七、文件关联
安装版安装时注册 .prdproj。便携版请点击左下“关联 .prdproj 文件”。
如果 Windows 已给此类型指定了其他程序，请右键文件→打开方式，选择 PRD 工作台并设为默认。
移动便携 EXE 的位置后，需要重新关联。

八、归档交付
“只读归档”导出完整离线 HTML，包含已提交正文、表格、评审与卡片历史。
归档无需安装软件即可在浏览器中查看，不包含未提交编辑草稿；交付前请先提交编辑。
可编辑协作时发送 .prdproj。当前版本为本地单人文档工具，同一文件不支持多人同时写入。

九、开发与验证
源码位于本目录 desktop，依赖位于 node_modules，测试结果位于 test-results。
双击本目录“启动最新版.bat”查看最新源码界面；现有 EXE 仅包含上次打包的功能。
在本目录执行 npm install / npm start：本地开发；npm test：存储测试。
仅在用户明确要求打包时执行 npm run build，新的安装版与便携版输出到本目录 releases。
上级目录两份原始 HTML 和用户创建的“运行.bat”均原位保留且未修改；工程使用 desktop/templates 中的独立模板副本。
当前版本沿用 Vue 2 / Element UI 编辑界面，所有依赖均已本地打包。
原型关联：文档标题下方点击关联对应原型，可填写 http/https 网址或选择本地 HTML、PDF、图片、RP、FIG、XD 文件。关联随当前 PRD 保存，支持修改和解除；本地路径按 PRD 所在位置相对记录。
评审录音：顶部按钮打开录音列表，支持上传、播放、下载、删除；转写文本和会议纪要可编辑并随 PRD 保存。软件内已移除模型配置和直接调用模型入口，后续拟通过 MCP 对接外部分析与纪要写回，目前尚未实现 MCP。
麦克风录音：评审记录总览左侧为两段按钮，评审录音打开管理窗口，开始录音请求麦克风权限；结束录音释放设备并将真实MP3保存到当前PRD所属项目根目录的评审录音文件夹，不自动加入PRD录音列表；需要时由用户通过“上传录音”手动添加，PRD只保存路径和评审信息。录音时显示计时并禁止切换PRD，保存失败支持重试；首次需要在浏览器/系统中允许麦克风。不设置录音时长和文件大小上限。新录音分段落盘，PRD保存相对引用；迁移请携带项目目录，或使用软件“另存为”复制音频。异常退出后重开PRD会尝试恢复已落盘的音频文件，但不自动导入；最后未落盘的片段可能丢失。
UX优化预览：左下角月亮/太阳图标切换暗黑或浅色主题，主题偏好保存在本机，自动同步到编辑器与弹框，不写入PRD正文。模块栏支持按名称搜索；保存按钮、导航选中态、表单和卡片样式已统一。本轮仅更新源码与预览，releases内1.1.0 EXE仍为功能基础版。
